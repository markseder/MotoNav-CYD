# MotoNav-CYD V1.0 Stable

Первый стабильный релиз проекта после реальных испытаний на CYD.

## Главное

- GPS-спидометр и поездочный компьютер;
- надёжная ручная GPX-запись;
- итоговая статистика и CSV;
- история последних 20 поездок на самом CYD;
- GNSS-диагностика;
- фильтрация скорости и дистанции;
- восстановление GPX после обрыва питания;
- дневная и ночная темы;
- автоматический переход на спидометр при движении.

## Установка

Скачайте папку `firmware/motonav/MotoNav_CYD_V1_0_Stable` полностью. INO и `config.h` должны находиться рядом.

Подробнее: [Quick Start](QUICK_START.md).
