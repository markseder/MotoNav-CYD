# MotoNav output examples

These files were recorded by a real MotoNav-CYD V1.1.2 test ride:

- `TRK_20260815_001357.GPX` — GPX 1.1 route with 10 recorded GNSS points;
- `TRK_20260815_001357.CSV` — final statistics for the same ride;
- `RIDES_INDEX.CSV` — example ride-history index containing three completed rides.

The GPX file contains real coordinates. Use it only as a public import and visualization sample.

See [microSD format and GPX viewing instructions](../STORAGE_FORMAT.md).
