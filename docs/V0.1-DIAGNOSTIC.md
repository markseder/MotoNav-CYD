# V0.1 — диагностическая прошивка

Цель теста — отдельно подтвердить дисплей CYD, поток NMEA от UART GNSS и чтение/запись встроенной microSD до разработки спидометра.

## Требуется

- ESP32-2432S028R CYD с дисплеем ILI9341 320×240;
- любой UART GNSS, выдающий стандартные NMEA-сообщения;
- microSD, отформатированная в FAT32;
- Arduino IDE с пакетом плат ESP32;
- библиотеки `TFT_eSPI` и `TinyGPSPlus`.

## Подключение GNSS для настройки по умолчанию

| GNSS | CYD |
|---|---|
| TX | GPIO35 |
| RX | не подключать |
| GND | GND |
| VCC | по паспорту конкретного модуля |

GPIO35 работает только как вход, что подходит для приёма NMEA. Перед подключением питания обязательно проверить допустимое напряжение конкретной платы GNSS.

## Настройка

Откройте `config.h` рядом со скетчем и укажите:

- `GNSS_RX_PIN` — GPIO, куда подключён TX приёмника;
- `GNSS_TX_PIN` — обычно `-1` для V0.1;
- `GNSS_BAUD` — скорость NMEA: часто 9600, 38400 или 115200;
- GPIO встроенной microSD, если ревизия CYD отличается.

Для TFT_eSPI должна использоваться конфигурация проверенной платы CYD: ILI9341, rotation 1. Скетч вызывает `invertDisplay(true)`, как в Electrum Terminal.

## Ожидаемый результат

На экране должны появиться:

- `DISPLAY PASS`;
- `microSD WRITE PASS`;
- `NMEA UART DATA`;
- после фикса — `GNSS FIX VALID`;
- координаты, скорость, спутники и HDOP;
- `TEST KML CREATED`.

На карте создаются:

- `/MOTONAV_SD_TEST.TXT` — проверка записи;
- `/MOTONAV_V01_TEST.KML` — одна точка первого валидного GNSS-фикса.

KML в V0.1 является только диагностическим файлом, а не записью полной поездки.

## Если NMEA не появляется

1. Проверить общую землю.
2. Проверить соединение `GNSS TX -> CYD GNSS_RX_PIN`.
3. Перебрать реальные скорости UART в `config.h`: 9600, 38400, 115200.
4. Открыть Serial Monitor на 115200 бод.
5. При необходимости раскомментировать `Serial.write(c)` для просмотра сырых NMEA-строк.

## Что записать в журнал теста

- ревизию CYD;
- модель GNSS;
- выбранную скорость UART;
- статусы на экране;
- спутники и HDOP на открытом месте;
- открывается ли KML в Google Earth или QGIS;
- фотографию подключения и экрана.
