# Технические источники

## Репозитории

- [CYD_GPS_Speedometer](https://github.com/stevedee78/CYD_GPS_Speedometer) — GPS-скорость, средняя/максимальная скорость, пробег и идеи интерфейса CYD.
- [TrailNav](https://github.com/Mastr00/trail_GPS) — архитектура GNSS, расчёт пути и устойчивые приёмы работы с microSD.

## Наши проверенные наработки

- Electrum Terminal — конфигурация CYD с ILI9341, сенсорным экраном и известными GPIO.
- MicroMark — диагностические наработки для UART GNSS, NMEA и безопасной записи на SD.

Источники используются как ориентиры. Код и лицензии каждого внешнего проекта необходимо проверить до прямого переноса фрагментов.
