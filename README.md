# MotoNav-CYD

Открытый GPS-спидометр и поездочный компьютер для мотоцикла на базе ESP32-2432S028R (CYD).

## Цель версии 1.0

- крупная текущая скорость по данным GNSS;
- Trip A, средняя и максимальная скорость;
- общее время поездки и время движения;
- количество спутников и качество позиционирования;
- запись маршрута в KML на встроенную microSD;
- дневной и ночной интерфейс;
- безопасное завершение и периодический сброс данных на карту.

## Совместимость GNSS

Проект не привязан к конкретному приёмнику. Поддерживается UART GNSS, передающий стандартные NMEA-сообщения. Пины и скорость UART будут вынесены в настройки.

GT-U12 используется как первый тестовый модуль. Также предполагается совместимость с ATGM336H, NEO-M8N, TAU1201 и другими NMEA-совместимыми приёмниками.

## Платформа первой сборки

- CYD ESP32-2432S028R;
- дисплей ILI9341, 320×240;
- встроенный слот microSD;
- UART GNSS;
- библиотека TinyGPSPlus.

## Состояние

Проект находится на этапе V0.1: подготовка диагностической прошивки для совместной проверки дисплея, GNSS и microSD.
