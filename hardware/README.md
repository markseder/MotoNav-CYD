# Аппаратная часть

## Основные компоненты

- ESP32-2432S028R CYD;
- UART GNSS с NMEA;
- встроенная microSD;
- преобразователь питания мотоцикла 12–14,5 В → стабильные 5 В;
- предохранитель и защита от импульсных помех;
- брызгозащищённый корпус.

## Предварительное подключение GNSS

| GNSS | CYD | Примечание |
|---|---|---|
| TX | настраиваемый GNSS_RX | вход NMEA в ESP32 |
| RX | настраиваемый GNSS_TX | необязательно для V0.1 |
| GND | GND | общая земля |
| VCC | по паспорту модуля | проверить допустимое напряжение |

Первый кандидат для входа NMEA — GPIO35, использованный в Electrum Terminal. Перед фиксацией схемы необходимо проверить ревизию платы и отсутствие конфликта с периферией.

## Встроенная microSD стандартного CYD

| Сигнал | GPIO |
|---|---:|
| CS | 5 |
| MOSI | 23 |
| MISO | 19 |
| SCK | 18 |

Пины требуется подтвердить на конкретной ревизии CYD до подключения дополнительной периферии.
