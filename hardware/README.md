# Аппаратная часть MotoNav-CYD V1.0

## Компоненты

- ESP32-2432S028R (CYD);
- UART GNSS с NMEA, 9600 baud;
- microSD FAT32;
- стабилизированное питание 5 В;
- для мотоцикла: преобразователь 12–14,5 В → 5 В, предохранитель, защита от импульсов и влагозащищённый корпус.

## GNSS

| GNSS | CYD | Примечание |
|---|---:|---|
| TX | GPIO35 | NMEA-вход ESP32 |
| RX | не подключать | V1.0 не передаёт команды в GNSS |
| GND | GND | общая земля |
| VCC | по паспорту модуля | не подавать неизвестное напряжение |

Проверенная скорость — 9600 baud. Если данные отсутствуют, сначала проверьте baud rate и общую землю.

## Встроенная microSD

| Сигнал | GPIO |
|---|---:|
| CS | 5 |
| MOSI | 23 |
| MISO | 19 |
| SCK | 18 |

V1.0 использует ESP32 SPI3 через `SPIClass sdSpi(3)`. Это сохраняет совместимость с ESP32 Arduino Core 3.x, где старое имя `VSPI` может быть недоступно.

## Сенсор XPT2046

| Сигнал | GPIO |
|---|---:|
| CS | 33 |
| IRQ | 36 |
| MOSI | 32 |
| MISO | 39 |
| CLK | 25 |

## Питание на мотоцикле

Не подключайте CYD непосредственно к 12-вольтовой бортовой сети. Нужны стабилизированные 5 В, общий минус, предохранитель у источника и защита от выбросов напряжения. Финальный монтаж должен исключать вибрацию разъёмов, попадание воды и замыкание открытых контактов.
