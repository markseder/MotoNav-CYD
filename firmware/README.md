# Прошивка

Здесь будут храниться проверенные версии прошивки MotoNav-CYD.

Планируемая структура:

- `diagnostic/` — V0.1, проверка CYD, GNSS и microSD;
- `motonav/` — основная прошивка;
- `config/` — примеры конфигураций плат и GNSS.

Основная логика не должна зависеть от модели GNSS. Настройки UART, GPIO и пороги фильтрации выносятся из прикладного кода.
