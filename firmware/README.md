# Прошивка

Здесь хранятся проверяемые версии прошивки MotoNav-CYD.

## V0.1 — диагностика

Скетч: [MotoNav_CYD_V0_1_Diagnostic.ino](diagnostic/MotoNav_CYD_V0_1_Diagnostic/MotoNav_CYD_V0_1_Diagnostic.ino)

Настройки UART, GPIO GNSS и встроенной microSD вынесены в соседний `config.h`. Прошивка проверяет:

- дисплей ILI9341;
- поступление NMEA по UART;
- фиксацию, координаты, скорость, спутники и HDOP;
- инициализацию и запись microSD;
- создание валидного диагностического KML с первой точкой фикса.

Инструкция: [V0.1 — диагностическая прошивка](../docs/V0.1-DIAGNOSTIC.md).

## V0.2 — экран GPS-спидометра

Скетч: [MotoNav_CYD_V0_2_Speedometer.ino](motonav/MotoNav_CYD_V0_2_Speedometer/MotoNav_CYD_V0_2_Speedometer.ino)

Первая рабочая версия интерфейса показывает крупную скорость, статус GNSS, спутники, HDOP и время UTC. Касание переключает дневную и ночную темы.

Инструкция: [V0.2 — экран GPS-спидометра](../docs/V0.2-SPEEDOMETER.md).

## Структура

- `diagnostic/` — диагностические этапы;
- `motonav/` — основная прошивка;
- `config/` — примеры конфигураций плат и GNSS.

Основная логика не зависит от модели GNSS. Настройки UART, GPIO и пороги фильтрации выносятся из прикладного кода.
