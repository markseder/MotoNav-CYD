# Журнал испытаний

Для каждого теста фиксируются:

- дата;
- ревизия CYD;
- модель GNSS;
- скорость UART;
- версия прошивки;
- холодный и тёплый старт;
- количество спутников и HDOP;
- стабильность скорости;
- результат записи KML;
- состояние файла после штатного и аварийного отключения.

Первый тест: GT-U12 как один из совместимых NMEA-приёмников.
