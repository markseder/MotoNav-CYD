# Результаты испытания V0.1

Дата: 11 августа 2026 г.

## Итог

Диагностическая прошивка V0.1 успешно проверена на реальном стенде CYD с UART GNSS и встроенной microSD.

| Проверка | Результат |
|---|---|
| Дисплей CYD | PASS |
| Инициализация microSD | PASS |
| Запись на microSD | PASS |
| Приём NMEA по UART | DATA |
| GNSS-фикс | VALID |
| Создание тестового KML | CREATED |
| Чтение файлов на компьютере | PASS |

Во время зафиксированного теста приёмник видел 4 спутника, HDOP составлял 5,7. Это достаточно для проверки полного тракта данных и записи, но не является оценкой точности в движении: следующий дорожный тест следует выполнять на открытом небе.

## Решение

Этап V0.1 принят. Можно переходить к V0.2: основной экран GPS-спидометра с крупной текущей скоростью и базовой GNSS-телеметрией.
